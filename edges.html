echo Edges

Edges represent a physical, lossless flow of a single commodity. An edge is terminated on each end by connection to a port. Edges must begin and end on ports that have the same commodity type.

Edge constraint

Edges are used to apply a flow constraint. They do not have an optimisation variable associated with them. If an edge connects ports \(x\) and \(y\), which have variables \(p^x\) and \(p^y\), then we can write the following edge constraint:

\(p^x + p^y = 0\).

This constraint enforces that any flow imported by \(x\) must be exported by \(y\), and vice versa.
