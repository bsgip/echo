class echo.models.base.edge.Edge(*, uid: str = None, edge_name: str | None = None, vertices: tuple[Port, Port], nodes: tuple[str, str] | None = None, tariff: list | None = None)

Bases: BaseModel

Edges are used to connect nodes. For an edge (x, y) where x and y are nodes, the edge value is equal to the flow from x->y plus the flow from y->x.
