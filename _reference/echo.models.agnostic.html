This node has an additional variable, ‘total’, which equals the sum of all ports defined on the node. port_units attribute is used for validation, all ports must be the same commodity.

Bases: InputOutputNode

A Node with an input and output and time varying piecewise relationship between input and output.

The relationship between input and output is defined at each time interval by an array of input–>output point pairs, which are used to construct a piecewise constraint. Attributes input_port_unit and output_port_unit define node’s commodity.
