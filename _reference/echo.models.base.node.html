echo.models.base.node module

class echo.models.base.node.Node(*, node_name: str = '', uid: str = None, ports: dict[str, Port] = {}, objective: NumericExpression | float = 0)

Bases: BaseModel

Nodes are collections of one or more ports that can include non-trivial relationships between the ports, this allows transformations to be implemented.

add_objective(model: EchoConcreteModel) → None

Define objective/s and add to self.objective. To be overwritten.

Should be implemented as an expression that needs to be concatanated to self.objective. For example:

total = 0

if self.regularise is True:
total += (
sum(

getattr(model, self.flow_value)[p, t] * getattr(model, self.flow_value)[p, t] for p in model.Expansion for t in model.Time

) * 0.0000001

)

self.objective += total
