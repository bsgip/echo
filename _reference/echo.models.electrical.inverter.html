echo.models.electrical.inverter module

class echo.models.electrical.inverter.Inverter(*, node_name: str = '', uid: str = None, ports: dict[str, Port] = {}, objective: NumericExpression | float = 0, max_import: float | None = None, max_export: float | None = None, dc_ac_efficiency: ConstrainedFloatValue = 1.0, ac_dc_efficiency: ConstrainedFloatValue = 1.0, ac_port_name: str | None = None, dc_port_names: list[str] = None)

Bases: Node

An inverter is a node with one AC port and at least one DC port. Flows from AC to DC, and DC to AC, are subject to conversion efficiencies.

Ports can be specified at construction time using the ac_port_name and dc_ports_names or the ports can be added later by making one call to add_ac_port and as many calls to add_dc_port as required. It is best not to mix these two approaches.

When creating ports through the constructor, the ports will be assigned default uids. If you need to flexibility of specifying uids for the ports then use the add_ac_port and add_dc_ports remembering to supply uid values.
